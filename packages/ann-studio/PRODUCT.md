# Product

## Register

product

## Users

G-Maiden announcer-pack authors create voice, banner, and overlay-event assets before a Dota 2 match. Their primary task is composing, previewing, and exporting a pack without changing the live game overlay by accident.

## Product Purpose

G-AnnStudio is the local authoring tool for G-Maiden announcer packs. It must let an author build a visual event banner with the direct manipulation expected from a professional design editor, then export a runtime-safe asset for G-Maiden.

## Brand Personality

Precise, expressive, and focused. The interaction model may take inspiration from Figma and Canva, but G-AnnStudio must retain its own G-Series identity and must not copy either product's branding or visual assets.

## Anti-references

- A form-only settings page that hides composition behind numeric fields.
- A decorative dashboard with no reliable layer selection, history, or export result.
- A generic cloud drive that exposes an author's pack or assets publicly.

## Design Principles

1. Direct manipulation and precise numeric editing must agree.
2. Every preview represents the asset that G-Maiden can actually render.
3. One drag is one undoable authoring action.
4. Source media remains immutable; projects store non-destructive edits.
5. Cloud sync protects private authoring work and never carries game-state data.

## Accessibility & Inclusion

Keyboard access, visible focus, labels for every icon action, non-color-only state, and reduced-motion alternatives are required. Canvas authoring must retain a keyboard-accessible layer and inspector path.
