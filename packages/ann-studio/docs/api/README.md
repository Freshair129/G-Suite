# G-AnnStudio API Index

The only documented cross-application contract in this slice is [Overlay layout sync](../g-overlay-lab.md): `POST http://127.0.0.1:3000/overlay/layout` with the versioned 19-module layout schema.

Banner projects and private cloud sync have no cross-application API contract. Do not infer one from this index.
