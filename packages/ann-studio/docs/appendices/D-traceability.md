## Gaps before implementation

1. Group transform and rotation handles are still absent from the local editor.
2. History snapshots are bounded and pointer transforms are grouped; patch-command history is still a future refinement.
3. The local canvas and candidate export path now share the BannerProject layer/timing model; live Ann Pack filesystem inspection and target G-Maiden renderer smoke remain open.
4. Source-video trim, encoded-byte budget, bake-error handling, and target runtime handoff remain open; per-layer timing validation is implemented in pure preflight.
5. Private cloud sync has no approved identity, RLS/authorization, storage, conflict, or deletion contract.
