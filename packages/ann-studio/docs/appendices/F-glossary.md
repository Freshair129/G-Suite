# Appendix F — Glossary

| Term | Meaning |
| --- | --- |
| Ann Pack | A G-Maiden-compatible announcer bundle containing mapped voice and banner assets. |
| BannerProject | The local, non-destructive layer document used by G-Overlay Lab. |
| C-3/HIGH | Architecture-driven, high-risk work requiring approved documentation and stronger verification. |
| G-AnnStudio | The desktop authoring tool for G-Maiden announcer packs. |
| G-Maiden | The companion application that renders the live Dota overlay. |
| GSI | Dota 2 Game State Integration; it is excluded from banner-project cloud storage. |
| HUD | Heads-up display; in this slice, the passive G-Maiden Combat HUD. |
| OverlayLayout | The 19-module screen-relative layout draft explicitly synced to G-Maiden. |
| Runtime-safe asset | Static or baked animated image format that G-Maiden can render without a raw video player. |
